# Face detection fixture

`astronaut.png` is the NASA portrait of Eileen Collins distributed with scikit-image v0.24.0. The scikit-image dataset documentation identifies this image as public domain with no known copyright restrictions.

- Source: https://raw.githubusercontent.com/scikit-image/scikit-image/v0.24.0/skimage/data/astronaut.png
- Dataset and attribution: https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut
- NASA image source linked by the dataset: https://flic.kr/p/r9qvLn

Used only to verify face detection with Apple's Vision framework. This fixture is not linked into the library or the example application.
